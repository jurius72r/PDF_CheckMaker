Учебный проект PDF check maker.
+-----------------------------------------------------+
Программа позволяет из .csv файлов содержащих данные:
- invoice_id,   # ID заказа в виде {Год-номер}
- customer,     # имя контрагента
- description,  # описание товара/услуги
- amount,       # стоимость товара/услуги
- currency;     # валюта счета
+-----------------------------------------------------+
Создавть чек в формате PDF;
Сохранять чек в папке /output в формате PDF;
Автоматически показывать получившийся файл в браузуре.

После установки зависимостей нужно в терминале запустить:
python pdf-checkmaker.py

Данную програмку можно использовать как надстройку к проектам нуждающимся
в предоставлении чеков клиентам. Актуально для самозанятых, ИП и юр. лиц 
ведущих онлайн бизнес и не имеющих возможность предоставлять кассовую от-
четность в оффлайне своим клиентам.
