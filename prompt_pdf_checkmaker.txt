Напиши готовый к запуску Python-скрипт для выбора счета (чека) из CSV- или JSON-файла и создания PDF на основе HTML-шаблона.

### Работа с файлами

- Используй каталоги `data`, `templates` и `output`, расположенные рядом со скриптом. Создавай `output`, если он еще не существует.
- Найди в `data` все файлы с расширениями `.csv` и `.json`, а в `templates` — все файлы `.html`. Поиск файлов должен быть нечувствительным к регистру расширения.
- CSV читай стандартным модулем `csv` (использовать `pandas` необязательно). Корректно обрабатывай UTF-8 и UTF-8 с BOM.
- JSON читай стандартным модулем `json`. Поддержи JSON-массив объектов и объект, содержащий массив счетов в поле `invoices`.
- Для каждого счета ожидай поле `invoice_id`. Если структура файла или обязательное поле отсутствуют, выведи понятное сообщение об ошибке.

### Выбор в консоли

- Выводи нумерованные списки найденных файлов данных и HTML-шаблонов.
- Предложи пользователю через `input()` выбрать один файл данных и один шаблон. Проверь ввод: номер должен соответствовать пункту списка; при ошибке попроси повторить выбор.
- Покажи нумерованный список доступных счетов по `invoice_id` из выбранного файла и предложи выбрать один счет.
- Если файлов, шаблонов или счетов нет, сообщи об этом и корректно заверши работу.

### Формирование PDF

- Подставь все поля выбранного счета в HTML-шаблон. Используй в шаблонах плейсхолдеры формата `{{ field_name }}`, где `field_name` — имя поля CSV или JSON.
- Экранируй подставляемые значения для HTML.
- Создай PDF с помощью библиотеки WeasyPrint и сохрани его в `output`. Имя файла должно содержать `invoice_id`; обработай символы, недопустимые в имени файла.
- Обеспечь корректное отображение кириллицы: укажи в CSS шаблона шрифт DejaVu Sans или Roboto с подходящим запасным шрифтом.
- После успешного создания автоматически открой PDF в стандартной программе операционной системы: используй подходящий способ для Windows и macOS.
- Если генерация или открытие PDF не удалось, выведи понятное сообщение с причиной, не сообщая об успехе.

Сделай решение совместимым с Windows и macOS, аккуратно оформи консольный вывод и добавь краткую инструкцию по установке зависимостей и запуску скрипта. В ответе приведи полный текст скрипта и необходимые примеры структуры каталогов и шаблона.
